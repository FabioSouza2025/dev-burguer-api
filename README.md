# DevBurger API

Sistema backend para gerenciamento de pedidos de uma hamburgueria.

## Tecnologias

- Node.js
- Express
- PostgreSQL
- Sequelize
- JWT
- Multer
- Docker

## Funcionalidades

✔ Login
✔ Cadastro de usuários
✔ Produtos
✔ Categorias
✔ Pedidos
✔ Upload de imagens
✔ Administração

## Como executar

git clone...
npm install
docker compose up
npm run dev
