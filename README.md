# 🍔 CodeBurger (DevBurger) - Hamburgueria Digital

Uma aplicação web completa de uma hamburgueria digital criada durante a jornada de aprendizado no **DevClub**, sob mentoria de **Rodolfo Mori**. O projeto simula um cenário real de mercado, unindo uma interface dinâmica a uma lógica de negócios robusta.

## 🚀 Tecnologias Utilizadas

- **HTML5** & **CSS3** (Estruturação e estilização responsiva)
- **JavaScript (ES6+)** (Lógica de negócios e manipulação do DOM)
- **React.js** / **Node.js**

## 🎯 Principais Funcionalidades

- **Listagem Dinâmica:** Exibição do cardápio completo de hambúrgueres e bebidas.
- **Filtros Personalizados:** Separação de produtos por categoria utilizando métodos de array.
- **Carrinho de Compras Interativo:** Adição de itens, atualização de quantidades e cálculo automático dos valores.
- **Aplicação de Descontos:** Lógica visual para promoções e cupons.

## 🧠 Conceitos Praticados (JavaScript Avançado)

O maior objetivo deste projeto foi consolidar a manipulação de dados utilizando os métodos mais importantes do ecossistema JavaScript:

- `forEach()`: Para renderizar e listar cada item do cardápio na tela.
- `map()`: Para aplicar descontos percentuais nos preços dos produtos em tempo real.
- `filter()`: Para filtrar os produtos (ex: mostrar apenas opções veganas ou combos).
- `reduce()`: Para somar e calcular o valor total acumulado no carrinho de compras.

## 🛠️ Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/FabioSouza2025/dev-burguer-api
   ```
2. Acesse a primeira pasta do projeto:
   ```bash
   cd DevBurguerAPI-INTERFACE

   npm run dev
   ```
3. Acesse a segunda pasta do projeto:   
   ```bash
   cd DevBurguerAPI-Completo

   npm run dev
   ```
4. Abra o arquivo `index.html` no seu navegador (ou utilize a extensão Live Server no VS Code).
